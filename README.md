# Glowcery List

A World of Warcraft (WoW Forever, Interface 16001) addon. Track a recipe and every vendor item you still need for it gets a buy icon, a pulsing green glow and a "missing" count.

## Features
- Buy icon, glow and missing count on vendor items needed for tracked recipes
- Counts bags, bank, reagent bank and warband bank
- Tooltip line: "Tracked recipe: need X (missing Y)"
- Works with Blizzard's recipe tracking; falls back to a **Track buy** button in the classic profession window

## Install
Copy the `GlowceryList` folder into `World of Warcraft\_forever_\Interface\AddOns\`.

## Commands
- `/glowcery` – list tracked recipes
- `/glowcery clear` – untrack all
